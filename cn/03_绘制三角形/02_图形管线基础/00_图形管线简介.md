# 图形管线简介

## 管线概览

图形管线是将网格的顶点和纹理一直处理到渲染目标中像素的**操作序列**。

```mermaid
graph LR
    IA[输入装配<br>🟢 固定功能] --> VS[顶点着色器<br>🟠 可编程]
    VS --> TS[曲面细分<br>🟠 可选]
    TS --> GS[几何着色器<br>🟠 可选]
    GS --> Rast[光栅化<br>🟢 固定功能]
    Rast --> FS[片段着色器<br>🟠 可编程]
    FS --> CB[颜色混合<br>🟢 固定功能]
    CB --> FB[帧缓冲<br>输出]
    
    style VS fill:#ff9800,color:#fff
    style TS fill:#ff9800,color:#fff
    style GS fill:#ff9800,color:#fff
    style FS fill:#ff9800,color:#fff
    style IA fill:#4caf50,color:#fff
    style Rast fill:#4caf50,color:#fff
    style CB fill:#4caf50,color:#fff
```

### 各阶段详解

| 阶段 | 类型 | 功能 |
|------|------|------|
| **输入装配** | 固定功能 | 从缓冲区收集原始顶点数据，可使用索引缓冲 |
| **顶点着色器** | 可编程 | 对每个顶点施加变换（模型空间→屏幕空间），传递逐顶点数据 |
| **曲面细分** | 可编程（可选） | 基于规则细分几何体，提高网格质量 |
| **几何着色器** | 可编程（可选） | 对每个图元操作，可丢弃或生成新图元（性能一般，不常用） |
| **光栅化** | 固定功能 | 将图元离散化为片段（像素），进行深度测试和裁剪 |
| **片段着色器** | 可编程 | 确定每个片段写入帧缓冲的颜色和深度值 |
| **颜色混合** | 固定功能 | 混合映射到同一像素的不同片段（如透明度混合） |

> ⚠️ **与 OpenGL/Direct3D 的关键区别**：
> - Vulkan 的图形管线**几乎完全不可变**（immutable）
> - 切换着色器或改变顶点布局 → 必须**完全重新创建管线**
> - 需要为所有不同组合**提前创建** `VkPipeline` 对象
> - **没有默认状态**——所有状态必须显式设置
> - **好处**：等同于预编译 vs 即时编译，驱动有更多优化机会
