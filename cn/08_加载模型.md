## 加载模型

```c++
#include <unordered_map>

std::vector<Vertex> vertices;
std::vector<uint32_t> indices;

void loadModel() {
    tinyobj::attrib_t attrib;                    // 顶点属性（位置、法线、纹理坐标）
    std::vector<tinyobj::shape_t> shapes;        // 独立的对象/组
    std::vector<tinyobj::material_t> materials;  // 材质
    std::string warn, err;

    if (!tinyobj::LoadObj(&attrib, &shapes, &materials, &warn, &err, MODEL_PATH)) {
        throw std::runtime_error(warn + err);
    }

    std::unordered_map<Vertex, uint32_t> uniqueVertices{};  // 去重

    for (const auto& shape : shapes) {
        for (const auto& index : shape.mesh.indices) {
            Vertex vertex{};

            vertex.pos = {
                attrib.vertices[3 * index.vertex_index + 0],
                attrib.vertices[3 * index.vertex_index + 1],
                attrib.vertices[3 * index.vertex_index + 2]
            };

            vertex.texCoord = {
                attrib.texcoords[2 * index.texcoord_index + 0],
                1.0f - attrib.texcoords[2 * index.texcoord_index + 1]  // ⚠️ 翻转 V
            };

            vertex.color = {1.0f, 1.0f, 1.0f};

            // 顶点去重——相同顶点只存一份
            if (uniqueVertices.count(vertex) == 0) {
                uniqueVertices[vertex] = static_cast<uint32_t>(vertices.size());
                vertices.push_back(vertex);
            }
            indices.push_back(uniqueVertices[vertex]);
        }
    }
}
```

> ⚠️ **纹理坐标 V 翻转**：OBJ 格式中 V=0 在图像底部，Vulkan 中 V=0 在顶部，需要 `1.0f - texcoord.v`。

## 顶点哈希（去重所需）

为了使用 `unordered_map` 进行去重，需要为 `Vertex` 实现哈希：

```c++
#define GLM_ENABLE_EXPERIMENTAL
#include <glm/gtx/hash.hpp>

namespace std {
    template<> struct hash<Vertex> {
        size_t operator()(Vertex const& vertex) const {
            return ((hash<glm::vec3>()(vertex.pos) ^
                   (hash<glm::vec3>()(vertex.color) << 1)) >> 1) ^
                   (hash<glm::vec2>()(vertex.texCoord) << 1);
        }
    };
}
```

同时为 `Vertex` 添加 `operator==`：

```c++
bool operator==(const Vertex& other) const {
    return pos == other.pos && color == other.color && texCoord == other.texCoord;
}
```

## 修改缓冲区创建

索引类型从 `uint16_t` 改为 `uint32_t`（模型顶点超过 65535）：

```c++
// 索引缓冲区绑定
vkCmdBindIndexBuffer(commandBuffer, indexBuffer, 0, VK_INDEX_TYPE_UINT32);  // ← 改为 UINT32
```

> ⚠️ 模型顶点数可能超过 65535，必须使用 `uint32_t` 索引。

### 🔴 模型加载常见错误

#### 错误 1：`TINYOBJLOADER_IMPLEMENTATION` 多次定义

```c++
// ❌ 与 stb_image 相同的问题——在多个 .cpp 中定义
// 只能在一个 .cpp 文件中定义实现宏
#define TINYOBJLOADER_IMPLEMENTATION
#include <tiny_obj_loader.h>
// 其他文件只 #include 不加 #define
```

#### 错误 2：模型文件路径错误（最常见！）

```c++
// ❌ 路径错误 → LoadObj 返回 false → 异常
// 常见原因：
// 1. 相对路径相对于工作目录，不是源文件目录
// 2. 文件名大小写不匹配（Linux 区分大小写）
// 3. 路径分隔符错误（Windows 用 \，Linux 用 /）

// ✅ 调试技巧：打印实际工作目录
#include <filesystem>
std::cout << "Working dir: " << std::filesystem::current_path() << std::endl;

// ✅ 使用宏定义路径，方便修改
const std::string MODEL_PATH = "models/viking_room.obj";
const std::string TEXTURE_PATH = "textures/viking_room.png";
```

#### 错误 3：V 坐标忘记翻转

```c++
// ❌ 纹理显示错乱/上下颠倒
vertex.texCoord = {
    attrib.texcoords[2 * index.texcoord_index + 0],
    attrib.texcoords[2 * index.texcoord_index + 1]   // 未翻转！
};

// ✅ OBJ 的 V 轴与 Vulkan 相反，必须翻转
vertex.texCoord = {
    attrib.texcoords[2 * index.texcoord_index + 0],
    1.0f - attrib.texcoords[2 * index.texcoord_index + 1]  // ← 翻转 V
};
```

#### 错误 4：索引类型仍为 `uint16_t`

```c++
// ❌ 模型超过 65535 个顶点时溢出 → 渲染错乱
std::vector<uint16_t> indices;              // 最大 65535！
vkCmdBindIndexBuffer(cmd, buf, 0, VK_INDEX_TYPE_UINT16);

// ✅ 使用 uint32_t（最大约 42 亿）
std::vector<uint32_t> indices;
vkCmdBindIndexBuffer(cmd, buf, 0, VK_INDEX_TYPE_UINT32);
```

#### 错误 5：顶点去重时 Vertex 没有 operator== 和 hash

```c++
// ❌ 编译错误：unordered_map 需要 hash 和 ==
std::unordered_map<Vertex, uint32_t> uniqueVertices;  // 编译失败！

// ✅ 必须为 Vertex 提供这两个
bool operator==(const Vertex& other) const {
    return pos == other.pos && color == other.color && texCoord == other.texCoord;
}

// 并特化 std::hash<Vertex>（见前文代码）
```

#### 大模型性能提示

| 优化 | 方法 |
|------|------|
| 顶点去重 | `unordered_map`（本章已实现） |
| 索引优化 | 使用 meshoptimizer 库优化顶点缓存 |
| LOD | 远距离使用简化模型 |
| 加载格式 | glTF 比 OBJ 更现代，支持材质和动画 |

## 知识点总结

| 概念 | 说明 |
|------|------|
| tinyobjloader | 轻量级 OBJ 加载库（头文件库） |
| OBJ 格式 | 存储顶点位置、法线、纹理坐标和面 |
| 顶点去重 | `unordered_map` 哈希去重，减少顶点数据 |
| V 坐标翻转 | `1.0f - v`，OBJ 与 Vulkan Y 轴方向不同 |
| uint32_t 索引 | 模型顶点超过 65535 时必须使用 |
