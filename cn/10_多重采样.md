## 什么是 MSAA

**多重采样抗锯齿（MSAA）** 通过在每个像素多个位置采样来平滑几何体边缘的锯齿。

## 查询硬件支持

```c++
VkSampleCountFlagBits getMaxUsableSampleCount() {
    VkPhysicalDeviceProperties physicalDeviceProperties;
    vkGetPhysicalDeviceProperties(physicalDevice, &physicalDeviceProperties);

    VkSampleCountFlags counts = physicalDeviceProperties.limits.framebufferColorSampleCounts
                              & physicalDeviceProperties.limits.framebufferDepthSampleCounts;

    if (counts & VK_SAMPLE_COUNT_64_BIT) return VK_SAMPLE_COUNT_64_BIT;
    if (counts & VK_SAMPLE_COUNT_32_BIT) return VK_SAMPLE_COUNT_32_BIT;
    if (counts & VK_SAMPLE_COUNT_16_BIT) return VK_SAMPLE_COUNT_16_BIT;
    if (counts & VK_SAMPLE_COUNT_8_BIT)  return VK_SAMPLE_COUNT_8_BIT;
    if (counts & VK_SAMPLE_COUNT_4_BIT)  return VK_SAMPLE_COUNT_4_BIT;
    if (counts & VK_SAMPLE_COUNT_2_BIT)  return VK_SAMPLE_COUNT_2_BIT;

    return VK_SAMPLE_COUNT_1_BIT;
}

VkSampleCountFlagBits msaaSamples = VK_SAMPLE_COUNT_1_BIT;  // 默认无 MSAA
```

## 创建多重采样颜色资源

MSAA 需要一个**多重采样颜色图像**作为渲染目标，最后 resolve 到交换链图像：

```c++
VkImage colorImage;
VkDeviceMemory colorImageMemory;
VkImageView colorImageView;

void createColorResources() {
    VkFormat colorFormat = swapChainImageFormat;

    createImage(swapChainExtent.width, swapChainExtent.height, 1,
        msaaSamples,  // ← 多重采样数
        colorFormat, VK_IMAGE_TILING_OPTIMAL,
        VK_IMAGE_USAGE_TRANSIENT_ATTACHMENT_BIT | VK_IMAGE_USAGE_COLOR_ATTACHMENT_BIT,
        VK_MEMORY_PROPERTY_DEVICE_LOCAL_BIT, colorImage, colorImageMemory);

    colorImageView = createImageView(colorImage, colorFormat, VK_IMAGE_ASPECT_COLOR_BIT, 1);
}
```

## 修改渲染通道

```c++
// 颜色附件（多重采样）
VkAttachmentDescription colorAttachment{};
colorAttachment.samples = msaaSamples;  // ← 多重采样
colorAttachment.finalLayout = VK_IMAGE_LAYOUT_COLOR_ATTACHMENT_OPTIMAL;  // 不直接呈现

// 颜色 Resolve 附件（交换链图像，单采样）
VkAttachmentDescription colorAttachmentResolve{};
colorAttachmentResolve.samples = VK_SAMPLE_COUNT_1_BIT;
colorAttachmentResolve.loadOp = VK_ATTACHMENT_LOAD_OP_DONT_CARE;
colorAttachmentResolve.storeOp = VK_ATTACHMENT_STORE_OP_STORE;
colorAttachmentResolve.finalLayout = VK_IMAGE_LAYOUT_PRESENT_SRC_KHR;

// 深度附件
VkAttachmentDescription depthAttachment{};
depthAttachment.samples = msaaSamples;  // ← 深度也需要多重采样

// 子通道
VkAttachmentReference colorAttachmentRef{};
colorAttachmentRef.attachment = 0;

VkAttachmentReference depthAttachmentRef{};
depthAttachmentRef.attachment = 1;

VkAttachmentReference colorAttachmentResolveRef{};
colorAttachmentResolveRef.attachment = 2;  // resolve 目标

subpass.pResolveAttachments = &colorAttachmentResolveRef;  // ← 新增
```

## 知识点总结

| 概念 | 说明 |
|------|------|
| MSAA | 多重采样抗锯齿，在边缘处多点采样 |
| 采样数 | 常用 4x，越高质量越好但性能越低 |
| Resolve | 将多重采样图像合并为单采样最终输出 |
| 附件顺序 | 颜色(MS) → 深度(MS) → Resolve(1x) |
| `TRANSIENT_ATTACHMENT` | 多重采样图像不需要持久存储 |

> 💡 4x MSAA 是性能与质量的良好平衡点，大多数桌面 GPU 都支持。

### 🔴 MSAA 常见错误

#### 错误 1：颜色和深度采样数不一致

```c++
// ❌ 颜色用 4x，深度仍是 1x → Vulkan 验证层报错
colorAttachment.samples = VK_SAMPLE_COUNT_4_BIT;
depthAttachment.samples = VK_SAMPLE_COUNT_1_BIT;  // 不一致！

// ✅ 颜色和深度的采样数必须完全一致
colorAttachment.samples = msaaSamples;
depthAttachment.samples = msaaSamples;   // ← 相同！
```

#### 错误 2：帧缓冲附件顺序与渲染通道不匹配

```c++
// ❌ 交换链图像放在了索引 0，但渲染通道的 attachment 0 是多重采样图像
std::array<VkImageView, 3> attachments = {
    swapChainImageViews[i],  // ❌ 这是 resolve 目标，应该在最后
    depthImageView,
    colorImageView
};

// ✅ 顺序：MS颜色, MS深度, resolve目标
std::array<VkImageView, 3> attachments = {
    colorImageView,           // 0: 多重采样颜色
    depthImageView,           // 1: 多重采样深度
    swapChainImageViews[i]    // 2: resolve 目标
};
```

#### 错误 3：多重采样图像的 `finalLayout` 设为 `PRESENT_SRC`

```c++
// ❌ 多重采样图像不能直接呈现！
colorAttachment.finalLayout = VK_IMAGE_LAYOUT_PRESENT_SRC_KHR;
// 验证层警告 + 渲染错误

// ✅ 多重采样图像只是渲染目标，resolve 附件才呈现
colorAttachment.finalLayout = VK_IMAGE_LAYOUT_COLOR_ATTACHMENT_OPTIMAL;
colorAttachmentResolve.finalLayout = VK_IMAGE_LAYOUT_PRESENT_SRC_KHR;
```

#### 错误 4：图形管线没有更新 `rasterizationSamples`

```c++
// ❌ 管线创建时仍用 1x → 渲染到多重采样帧缓冲时管线不兼容
multisampling.rasterizationSamples = VK_SAMPLE_COUNT_1_BIT;
// → 验证层报错：pipeline sample count does not match

// ✅ 管线的采样数必须与渲染通道匹配
multisampling.rasterizationSamples = msaaSamples;
```

#### 性能影响参考

| 采样数 | 显存增加 | GPU 负载增加 | 视觉提升 |
|--------|---------|-------------|---------|
| 1x | 基准 | 基准 | 无 |
| 2x | ~2x | ~20% | 明显改善 |
| 4x | ~4x | ~40% | 很好 |
| 8x | ~8x | ~80% | 边际递减 |

> 💡 **MSAA vs 后处理 AA**：MSAA 只平滑几何边缘，不处理着色器产生的锯齿（如高光/阴影边缘）。后处理方案（FXAA、TAA）处理所有类型的锯齿但会模糊画面。
